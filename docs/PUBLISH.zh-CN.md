# 发布与后续工作

本仓库的目标是公开可检查的证明代码并接受复现，不提前宣称首次解决。

## 本地和 GitHub 的关系

* D 盘目录是本地工作仓库；文件和提交记录都保存在这里。
* `git commit` 只生成本地版本，不会自动公开。
* 在 GitHub 创建公开仓库后，配置 `origin` 并执行 `git push -u origin main`，内容才会公开。
* 首次推送后检查 Actions：自动构建通过，才能称“GitHub 环境也已复现”。

不要把 `.git/`、`.lake/`、工具下载包或登录凭据上传到网页。用 Git 推送时，本仓库的忽略规则会排除构建目录；`.git/` 本身不会作为项目文件提交。

## 当前证明范围

已检查的是对任意非退化三角形边长成立的主不等式，采用标准的中线和内角平分线边长公式。没有使用未证明的叶节点正确性假设；局部解析证明、区间证书、覆盖、排序、缩放已全部接通。

“等号当且仅当三角形等边”的完整分类已在 Equality.lean 中形式化并通过本地编译。从欧氏点和距离重新推导长度公式尚未形式化；它不是已验证边长公式定理中的额外假设。

## 发布后优先做什么

1. 请另一人在独立环境重建并核对定义与原文猜想，保留检查意见。
2. 完成新颖性查证，检索等价公式及原文后续引用。没有搜索到解答不能等同于确认首解。
3. 将文字证明和 Lean 使用的局部估计统一，整理为可独立阅读的短论文。
4. 选择是否简化计算证书、推导欧氏点表述或寻找纯解析证明。
5. 查新和独立复核完成后，再考虑 arXiv。GitHub 公开本身不等于同行评审。
