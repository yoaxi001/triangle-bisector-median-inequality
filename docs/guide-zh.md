# 中文阅读指南：这个项目证明了什么？

这是一个物理专业学生出于兴趣、在 AI 辅助下开展的数学探索项目。项目选择在 GitHub 公开，让读者查看证明、复现验证和提出问题。

## 结论

对任意非退化三角形，记三条内角平分线的长度为 $w_a,w_b,w_c$，三条中线的长度为 $m_a,m_b,m_c$，半周长为 $s$，则

$$
(w_a+w_b+w_c)(m_a^3+m_b^3+m_c^3)\ge s^4.
$$

等号成立当且仅当三角形等边。

问题来自 Jian Liu 于 2024 年在 *International Journal of Geometry* 发表的文章，第 78 页猜想 5.1、公式 (5.2)。[原文](https://ijgeometry.com/wp-content/uploads/2024/09/6.-63-79.pdf)。虽然原文标题提到锐角三角形，这条猜想针对的是任意三角形；我们的最终定理也包括直角和钝角情形。

## 证明思路

先利用缩放和对称性，把三边整理成 $x,y,1$，其中 $0\le x\le y\le1$ 且 $x+y\ge1$。这样所有三角形都对应到一个二维区域。

接近等边三角形的部分用解析估计处理。将三边平均值归一化为 1，写成 $1+p,1+q,1+r$，其中 $p+q+r=0$、三者绝对值不超过 $1/10$。令 $T=p^2+q^2+r^2$，代码证明

$$
(\sum w_a)(\sum m_a^3)\ge\frac{81}{16}+\frac9{128}T.
$$

此时 $s^4=81/16$，所以等号只能出现在 $T=0$，也就是三边相等时。

其余部分用有限个矩形区间覆盖。每个区间保存六条长度的有理数下界，使用精确整数运算，证明这个区间里的所有三角形都满足严格不等式。不能包含目标区域点的区间则由明确的不等式排除。

完整证书包含 3030 个严格区间叶节点、87 个解析区域叶节点和 123 个空叶节点。覆盖关系本身也有证明，因此检查的是整个连续区域，区间之间没有遗漏。

严格区间不能出现等号，解析区域的等号又只能是等边情形；最后撤销缩放和排序，就得到全局等号分类。

## Lean 验证是什么意思？

Lean 是一个证明助手。我们把定义、假设和推导写成程序可检查的形式，由其内核检查推导是否符合逻辑规则。

这个项目包括两层检查：一层确认有限整数证书全部通过；另一层证明这些整数检查确实能够推出实数长度上的不等式，再证明所有目标点都被覆盖。只检查证书数值而不证明第二层，不足以得到本项目的最终定理。

最终两个定理使用的假设只有三边为正和三条严格三角形不等式；没有留下“假定所有区间都正确”之类的额外假设。源码没有 `sorry`、`admit`、`native_decide` 或另行假设的数学公理。

形式化中的中线和角平分线由标准边长公式定义；从欧氏几何点、角和中点出发推导这些公式的过程，没有在本项目中另行形式化。Lean 检查也不负责判断是否有人更早证明、成果影响力或是否经过同行评审。

## 如何复现？

安装 Git 和 [elan / Lean](https://lean-lang.org/install/)，取得仓库后，在仓库根目录执行：

```sh
lake exe cache get
lake build
lake env lean Main.lean
lake env lean Equality.lean
```

首次运行需要联网下载固定版本的工具和依赖。完整证书已经包含在仓库中，不需要重新运行 AI、搜索算法或 Python 生成程序。

`lake build` 检查全部五个证明模块，最后两条命令显示最终定理的公理依赖。最终两个定理的报告应只包含 Lean/mathlib 的标准基础项 `propext`、`Classical.choice`、`Quot.sound`。

也可以查看 [GitHub Actions 验证记录](https://github.com/yoaxi001/triangle-bisector-median-inequality/actions)，注意选中对应版本并确认结论为成功。自动复验和数学家的独立审查是不同的检查。
